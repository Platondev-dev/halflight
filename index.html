Концепт промо-афіші для techno-події: темна атмосфера клубу, лазери, дим, світлові спалахи та глітч-типографіка. Дві версії — статична для стрічки та Telegram і анімована для Stories / Reels, де лазери та стробоскоп рухаються в ритмі 140 BPM.

На весь екран

Ідея

Одне джерело світла в диму, з якого розходяться лазери, — як момент, коли в темному залі вмикається перший промінь. Назва велика, на всю ширину, з легким глітчем.

Ієрархія

Спершу назва, потім дата, місто й жанр у чіткій сітці. Яскрава плашка «Tickets on sale» внизу веде до покупки квитків.

Адаптація

Одна система для всіх форматів: 4:5 для стрічки, 9:16 для Stories і Reels, квадрат або горизонталь для Telegram за потреби.
